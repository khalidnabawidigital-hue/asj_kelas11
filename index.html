Bab 9 – DHCP Server

Belajar membuat server yang memberikan IP Address secara otomatis ke klien.

Praktik: Komputer client mendapatkan IP otomatis dari server Linux kita.
Buka Materi & Kuis

Bab 10 – DNS Server

Menerjemahkan IP Address menjadi nama domain (misal: www.sekolahku.sch.id).

Praktik: Client dapat mengakses server menggunakan nama domain sendiri, bukan menghafal IP.
Buka Materi & Kuis

Bab 11 & 12 – Web & Database Server

Apache PHP MariaDB

Membangun layanan hosting website dan menyimpan data pada tabel database.

Praktik: Website dinamis berhasil berjalan di server dan terhubung ke database.
Buka Materi & Kuis

Bab 13 & 14 – FTP & Samba File Server

  • FTP: Upload/download file web ke server.
  • Samba: Membuat folder sharing lintas OS.
Praktik: Komputer Windows client dapat membuka dan mentransfer file ke folder Linux.
Buka Materi & Kuis

Bab 15 & 16 – Backup, Restore & Monitoring

Menjaga data tetap aman dan mengecek resource server (CPU, RAM, Storage) secara real-time.

Praktik: Mengetahui kondisi kesehatan server dan melakukan simulasi backup database.
Buka Materi & Kuis

Bab 17 – Firewall Dasar

Allow Deny Ports
Praktik: Mengamankan server dengan menutup port yang tidak digunakan (iptables / ufw).
